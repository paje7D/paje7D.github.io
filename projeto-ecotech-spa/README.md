# EcoTech Solutions - Single Page Application (SPA)

## 📌 Sobre o Projeto
Aplicação Web One Page desenvolvida como Projeto Final da disciplina de Front-end. A **EcoTech Solutions** é uma iniciativa fictícia focada em auditoria energética e soluções sustentáveis baseadas em tecnologia IoT para micro e pequenas empresas.

---

## 🚀 Tecnologias Utilizadas
- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização customizada, efeitos de hover e responsividade.
- **Bootstrap v5.3:** Sistema de Grid, Navbar responsiva, Cards, Carrossel e utilitários.
- **JavaScript (ES6+):** Manipulação do DOM, interatividade dinâmica e validação de dados.
- **Formspree:** Serviço Front-end puro para recepção de mensagens de e-mail.
- **FontAwesome:** Biblioteca de ícones vetoriais.

---

## ⚡ Recursos em JavaScript Implementados
1. **Modo Escuro / Modo Claro (Dark Mode):** Alternância dinâmica do tema visual da aplicação alterando atributos globais do documento.
2. **Contadores Numéricos Animados:** Animação de contagem regressiva ativada dinamicamente via evento de rolagem (*scroll listener*).
3. **Validação Dinâmica de Formulário:** Validação dos 4 campos obrigatórios via Expressões Regulares (Regex) com feedback de erro em tempo real.
4. **Envio Assíncrono (AJAX / Fetch API):** Envio dos dados do formulário sem recarregamento de página (*page reload*).
